# 🤖 Smart Offline Chatbot

A smart rule-based chatbot built using HTML, CSS and JavaScript.

## 🚀 Features

- 500+ predefined questions and answers
- Smart keyword matching system
- Chat history using LocalStorage
- Dark / Light mode
- Typing animation
- Voice input support
- Responsive design
- Offline working chatbot

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON
- LocalStorage
- Web Speech API

## 📂 Project Structure

Smart-Chatbot/

├── index.html  
├── style.css  
├── script.js  
└── responses.json  

## 💡 How It Works

The chatbot uses a rule-based matching system.
User questions are matched with predefined keywords from the JSON database and the relevant response is displayed.
